# ASHA: Cancer Awareness & Support

A professional React web application providing cancer awareness, support resources, and inspirational content.

Live Website:https://asha-topaz.vercel.app/

## Features

- Responsive landing page with hero section
- Contact form with validation
- Real-time inspirational quotes from API
- Professional design with smooth animations
- Mobile-friendly responsive layout

## Installation

```bash
npm install
```

## Running the Application

```bash
npm start
```

The application will open at http://localhost:3000

## Building for Production

```bash
npm run build
```

## Technologies Used

- React 18
- Lucide React Icons
- CSS3 with modern features
- API Ninjas Quotes API
